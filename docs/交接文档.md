### 4.2 沙箱工具坑（会让你误以为程序坏了）

| 坑 | 表现 | 对策 |
|---|---|---|
| 🔴 **git 写 ref 会静默失败** | `git commit` 打印成功但 ref 没落盘 | **commit 后必须复核 `git rev-parse HEAD` / `git show-ref`**；绕法 = 手动 `printf '<sha>' > .git/refs/...` |
| 🔴 **沙箱注入 `SERVER__PORT`**（双下划线） | Spring 宽松绑定覆盖 `server.port` → 报「端口被占用」 | 启动前 `Remove-Item Env:SERVER__PORT`；**不要为此改项目配置** |
| ⚠️ **跑 `mvn` 前先清 MSYS 变量** | 报找不到 plexus launcher（不是 Maven 坏了） | `unset MSYS_NO_PATHCONV MSYS2_ARG_CONV_EXCL` |
| 🔴 **`Write` 工具写的 `.ps1` 无 BOM** | PowerShell 5.1 按 GBK 解析 → **中文串被打碎、脚本语法报错** | **脚本保持纯 ASCII，中文放 `.json` 数据文件**（本次已按此规避） |
| ⚠️ **`mysql.exe` 中文输出是 GBK** | 管道给 grep 被判二进制；日志里中文要按 GBK 读 | `Get-Content -Encoding Default` 或先重定向再 `iconv -f GBK -t UTF-8` |
| ⚠️ **PowerShell stdout 常丢** | 只回 exit code | 结果 `*>` 写文件后 Read |
| ⚠️ **docker CLI 在沙箱不可用** | `docker ps` 无输出 | 启停容器请用户在宿主机执行；Agent 只能从 6379 探活 |
| ⚠️ **安全过滤器拦含 `%XX` 字面量的命令** | 报 `cmd.exe %VAR% environment variable syntax` | 运行时用 `[uri]::EscapeDataString()` 生成 |
| ⚠️ **`Invoke-RestMethod` 按 Latin-1 解码** | 中文变乱码 | 用 `Net.WebClient` + `[Text.Encoding]::UTF8` |

## 7. 已经探明的坑（别重踩）

### 7.1 本轮（2026-09-23）新发现的

- 🔴 **TABOO 规则不能扫 `reason`**：会把「已要求不加香菜」判成 HIGH 违规 → **永远收不敛**。
  已修（`08303e4`），详见 `RULES-PIPELINE.md`。
- 🔴 **glm-5.3-flash 必须显式下发 `reasoning-effort`**（该系列强制思考、不能关闭），
  不传就按默认高档跑，表现为「超时且无返回」→ 看起来像挂死。已修（`61f249d`）。
- 🔴 **LLM 熔断阈值是硬编码默认值 3**（`sys_config` 里没有 `llm.breaker.*` 键，后台改不到）。
- ⚠️ **`meta.estCost` 实测常为 null**（原因未查透）；要成本数字先用 P4-C 公式手算。
- ⚠️ **触发重排的具体规则码没进日志**（只有 `VALIDATE` 一条 `success=0`）→ 无法分析「哪些规则最常导致重排」。

### 7.2 更早的、仍然有效的（择要）

- **百度地图**：`tag` 参数**填错不报错、只静默返回城市级垃圾**（比报错危险）→ 全面弃用，只发 `query`；
  `page_num` 从 **0** 起、请求 `origin` 是 `lat,lng` 而响应是 `lng`/`lat`；**AK 有误返回 `status=200`**；
  地点检索免费额度 **100 次/天**、并发 3 QPS（`status=401` 是并发超限不是日额度用完）
- **大模型**：POST **不重试**（429 例外，会重试）；降级链是**厂商粒度**；DashScope 模型 id **必须全小写**；
  推理模型思维链**计入 completion_tokens 且占用 max-tokens**
- **MyBatis-Plus**：`updateById` **默认跳过 null 字段**（要置 null 必须 delete+insert 或 `UpdateWrapper.set()`）；
  `SUM()` 对 INT 列返回 **DECIMAL**（聚合查询套 `CAST(... AS SIGNED)`）
- **Controller 路径**：`context-path` 已是 `/api`，`@RequestMapping` **只写应用内路径**
  （写成 `/api/trip` → 真实路径变 `/api/api/trip/...` → `NoResourceFoundException` + 500）
- **SSE**：前端**不能用 `EventSource`**（带不了 JWT），必须 `fetch` + `response.body.getReader()`；
  中断大模型流的唯一手段 = **在增量回调里抛异常**（上游 `forEach` 外套 try-with-resources）
- **JSON 响应里 null 字段会整个消失**（`jackson.default-property-inclusion: non_null`）→ 前端/测试用 `== null`

### 7.3 工程纪律

- **依赖纪律**：新增依赖必须先说明用途与版本，确认后再写进 `pom.xml` / `package.json`
- **别跑错目录**：`npm` 只在前端目录、`mvn` 只在后端目录
- **命名纪律**：`grep -r "photoshare\|photo-share" .` 必须为空
- **事实纪律**：接口路径、字段名、方法名必须来自真实代码；不确定就说「需要查文档」，**不要编造**
- **资料写入纪律**：文档里不得出现代码里不存在的能力
- **🔴 git 约定**：**Agent 只负责 `git commit`，`git push` 由用户在宿主机执行**
  （沙箱里凭据助手会挂住）。推送前必做泄漏复核：确认 `.env.properties` / `.workbuddy/` 不在提交树

## 9. 简历指标的诚实提醒

手册第 8 章把简历里的亮点翻译成了「代码里必须存在什么 + 怎么验证」。三条纪律：

1. **数字必须来自 P7-B 的实测**，不抄任何外部数字；
2. **数字不好看就如实写，并说明瓶颈在哪** —— 诚实比漂亮更有说服力；
3. **口径要写准**：例如 2-opt 的「平均 9.30%」里含两组 0%，必须写成
   「**当候选顺序存在明显交叉时**，2-opt 把总里程再降约 9%~25%；顺直点集改进为 0」，
   不能写成「平均降 9.3%」或「一律降 X%」。
