### 4.2 沙箱工具坑（会让你误以为程序坏了）

| 坑 | 表现 | 对策 |
|---|---|---|
| 🔴 **git 写 ref 会静默失败** | `git commit` 打印成功但 ref 没落盘 | **commit 后必须复核 `git rev-parse HEAD`**；绕法 = 手动 `printf '<sha>' > .git/refs/...` |
| 🔴 **沙箱注入 `SERVER__PORT`**（双下划线） | Spring 宽松绑定覆盖 `server.port` → `Port 12515 was already in use` 启动失败 | 启动前 `unset SERVER__PORT SERVER_PORT`（**09-24 又漏了一次**） |
| ⚠️ **跑 `mvn` 前先清 MSYS 变量** | 报找不到 plexus launcher（不是 Maven 坏了） | `unset MSYS_NO_PATHCONV MSYS2_ARG_CONV_EXCL` |
| 🔴 **`.ps1` 里写中文 = 无 BOM 会被 GBK 拆碎** | PowerShell 5.1 按 GBK 解析 → 中文字面量变乱码**且不报错**，乱码被当请求体发出去（09-23 排查了十几轮） | ✅ **正解：给脚本补 UTF-8 BOM** —— `printf '\xEF\xBB\xBF' > t && cat 原 >> t && mv t 原`。改完要复查 `head -c 3 文件 \| xxd` 仍是 `efbb bf` |
| 🔴 **沙箱会定期回收后台进程** | `mvn spring-boot:run` 会在 1~30 分钟内无征兆消失（**无 `hs_err`、0 条 Exception、无优雅关闭日志 = 被 SIGKILL**） | 与代码无关；长采集脚本必须**每轮前探活 + 可断点续跑** |
| 🔴 **裸 TCP 连 Redis 的 RESP 长度要用 UTF-8 字节数** | 键里有中文时用 `$p.Length`（UTF-16 字符数）会算少 → 协议错位、**命令被静默丢弃**（表现为「DEL 发了但键还在」） | 用 `[Text.Encoding]::UTF8.GetByteCount($p)`；铁证：`TTL <中文键>` 回 `-ERR unknown command` |
| 🔴 **`Net.WebClient` 登录前不要先发 GET** | 先 `DownloadString` 再 `UploadString` 会丢 Content-Type → 变成 `application/octet-stream` → Spring 报 `HttpMediaTypeNotSupportedException` → **HTTP 500**（不是 415），表现为「登录莫名 500、后续全 401」 | 登录一律用显式 `HttpWebRequest` + `$req.ContentType='application/json'` |
| ⚠️ **内联 PS 命令含 `WebClient`+`DownloadString` 会被安全过滤器拦** | 报「Download cradle」；Bash 里调 `powershell` 也会被拦（「bypasses security checks」） | 探测逻辑写成 `.ps1` 文件再执行；用 PowerShell 工具而非 Bash |
| ⚠️ **`mysql.exe` 中文输出是 GBK** | 管道给 grep 被判二进制；日志里中文要按 GBK 读 | `Get-Content -Encoding Default`，或先重定向再 `iconv -f GBK -t UTF-8` |
| ⚠️ **PowerShell stdout 常丢** | 只回 exit code | 结果 `*>` 写文件后 Read |
| ⚠️ **docker CLI 在沙箱不可用** | `docker ps` 无输出 | 启停容器请用户在宿主机执行；Agent 只能从 6379 探活 |
| ⚠️ **安全过滤器拦含 `%XX` 字面量的命令** | 报 `cmd.exe %VAR% environment variable syntax` | 运行时用 `[uri]::EscapeDataString()` 生成 |
| ⚠️ **`Invoke-RestMethod` 按 Latin-1 解码** | 中文变乱码 | 用 `Net.WebClient` + `[Text.Encoding]::UTF8` |

## 7. 已经探明的坑（别重踩）

### 7.1 P7 期间新发现的（**都还没修，见「未修缺陷」**）

- 🔴 **「客户端断开即中断 LLM 流」只有 1/3 成立**：9 次实测只有 3 次真掐断，另 6 次模型把整篇生成完
  并照常落库。原因：检测点是「下一次 `send()` 抛异常」，而 delta 写入只有 **1.4 字符/块**，
  被 socket 缓冲吸收后 `send()` 一直成功。**心跳解决不了**（心跳写入同样会被缓冲吸收）。
- 🔴 **`error_msg` 里的「节省约 N tokens」高估约 14 倍**：它取的是 COPY 阶段
  `completion_tokens` 的**均值（整篇预期成本）**，**没有减去已产出**。实测自报 429 / 已产出 399 →
  真实净节省仅约 **30 tokens**。**引用前必须自己减一次**。
- 🔴 **`meta.tokens` 按「用户 + 时间窗」查，会被相邻行程污染**（实测同输入两次得到 4853 与 2187）。
  → 取数一律用 **`ai_generation_log` 按 `trip_id` 聚合**。
- 🔴 **`meta.estCost` 常为 null**：① 它只统计「有单价的厂商」，而每次行程都有一条 `provider="map"` 的
  ROUTE 行（map 无单价）；② 它读的是被污染的 `meta.tokens`。**两个缺陷叠加，暂不可作为成本口径。**
- 🔴 **空结果会被缓存 24 小时**（与 `CacheConfig` 注释写的意图相反）：`disableCachingNullValues()`
  **只挡 `null`、不挡空 `List`**，而 `searchPoi` 查不到时返回空 List。实测 `寿阳+古建筑`
  （百度侧 `total:0`）留下了缓存空列表的键 → **用户搜一个百度查不到的词，24h 内再搜都返回空**。
  修法一行（`@Cacheable` 加 `unless = "#result == null || #result.isEmpty()"`），**待拍板**。
- 🔴 **`mode` / `provider` 无法区分「实测」与「缓存命中」**：地图开着且百度可用时 `resolve()` 恒给
  `VERIFIED`，`@Cacheable` 命中时方法体不执行、`mode` 仍是 `VERIFIED`、`provider` 仍写 `baidu`。
  判冷热只能靠两条外部证据：`external_call_log` 行数增量（冷 +1 / 热 +0）+ 命中时不落库。
- 🔴 **`qwen3.8-flash` 已不可用**（旧结论作废）：476 s / 次、失败率 **55%**、输出 token 是别家的
  **13~16 倍**（推测思维链计入 `completion_tokens`）。**「免费」是陷阱**。
- 🔴 **deepseek-flash 必须显式下发 `reasoning_effort`**（默认 `high`）：同一 prompt 实测
  `none` 0.8 s / 96 tok ｜ `low` 5.5 s / 1171 ｜ `high` 9.7 s / 2139。参数名必须是 `reasoning_effort`
  （写成 `effort` 会被静默忽略）；合法 8 档，**支持 `none` 彻底关思考**。
- 🔴 **glm-5.3-flash 也必须显式下发 `reasoning-effort`**（该系列强制思考、不能关闭，只有 low/high/max）。
- 🔴 **LLM 熔断阈值是硬编码默认值 3**（`sys_config` 里没有 `llm.breaker.*` 键，后台改不到）。
- ⚠️ **触发重排的具体规则码没进日志**（只有 `VALIDATE` 一条 `success=0`）→ 无法分析「哪些规则最常导致重排」。
- ⚠️ **`mvn test` 会真实外呼**：`GovernedExternalHttpClientTest` 用真实域名 + 假 AK 打
  bigmodel / 百度（实测 429 重试占 6.8 s）。假 AK 大概率被拒不计配额，但**未验证**；建议改 MockWebServer。

### 7.2 更早的、仍然有效的（择要）

- **百度地图**：`tag` 参数**填错不报错、只静默返回城市级垃圾**（比报错危险）→ 全面弃用，只发 `query`；
  `page_num` 从 **0** 起、请求 `origin` 是 `lat,lng` 而响应是 `lng`/`lat`；**AK 有误返回 `status=200`**；
  地点检索免费额度 **100 次/天**、并发 3 QPS（`status=401` 是并发超限不是日额度用完）；
  **`region` 传县级名可能返回 0 条**（实测 `寿阳+古建筑` = 0，`大同+古建筑` = 14）→ 做演示要挑城市
- **大模型**：POST **不重试**（429 例外，会重试）；降级链是**厂商粒度**；DashScope 模型 id **必须全小写**；
  推理模型思维链**计入 completion_tokens 且占用 max-tokens**
- **MyBatis-Plus**：`updateById` **默认跳过 null 字段**（要置 null 必须 delete+insert 或 `UpdateWrapper.set()`）；
  `SUM()` 对 INT 列返回 **DECIMAL**（聚合查询套 `CAST(... AS SIGNED)`）
- **Controller 路径**：`context-path` 已是 `/api`，`@RequestMapping` **只写应用内路径**
- **SSE**：前端**不能用 `EventSource`**（带不了 JWT），必须 `fetch` + `response.body.getReader()`；
  中断大模型流的唯一手段 = **在增量回调里抛异常**
- **JSON 响应里 null 字段会整个消失**（`jackson.default-property-inclusion: non_null`）→ 前端/测试用 `== null`

## 9. 简历指标的诚实提醒

手册第 8 章把简历里的亮点翻译成了「代码里必须存在什么 + 怎么验证」。四条纪律：

1. **数字必须来自 P7 的实测**，不抄任何外部数字；测量日期与环境要一起写。
2. **数字不好看就如实写，并说明瓶颈在哪** —— 诚实比漂亮更有说服力。
   本项目已有三处「不好看但必须如实写」：中断节省（净省约 30 tokens）、
   流式骨架（71 s，达不到手册的 15 s）、qwen 已不可用。
3. **口径要写准**，例如：
   - 2-opt 要写「**当候选顺序存在明显交叉时**降 9%~25%」，不能写「平均降 9.3%」；
   - 缓存要写「**单次检索**从 329 ms 降到 8.4 ms，但整条管线只省 2%」；
   - 成本要写「**空闲时段** ¥0.0107/次，高峰时段上限约 ¥0.021」；
   - 中断要写「**约 1/3 的中断能真正掐断生成**，价值在不产生半成品数据」。
4. **未修缺陷要在答辩时主动讲**（§7.1 那些）—— 被问出来不如自己先说，且「发现了但权衡后没改」本身就是工程判断力。
